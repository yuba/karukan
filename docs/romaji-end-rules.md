# テキスト末の規則（フォーク独自機能）

`romaji.tsv` のキーの末尾に `{composition-separator}` を付けると、その規則は入力の末尾でだけ働きます。azooKey / hazkey のローマ字テーブルと同じ書き方です。

```
n{composition-separator}	ん
```

`kan` と打って変換・確定すると「かん」になり、`kana` は「かな」のままです。普通の規則として `n	ん` を書くと、`n` を打った瞬間に「ん」になってしまい `na` が打てなくなりますが、テキスト末の規則は打鍵中には使われないため、そうした衝突が起きません。

- 適用されるのは、変換を始めるとき（Space など）と、ひらがなのまま確定するとき（Enter）です。
- 入力末尾の未確定部分に一致する、最も長いキーが使われます。
- 一致しなければ、これまでどおり打ったキーのまま残ります。
