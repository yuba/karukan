# キーバインドのカスタマイズ（フォーク独自機能）

`~/.config/karukan-im/keymap.toml` にキーと動作の対応を書くと、組み込みのキーバインドより優先して使われます。

```toml
[bindings]
"Ctrl+U" = "hiragana"
"Ctrl+I" = "katakana"
"Ctrl+P" = "alphanumeric_full"
"Ctrl+O" = "toggle_width"
"Shift" = "hiragana_mode"
```

読み込むのは起動時だけなので、変更したら `fcitx5 -r` で再起動してください。

## 動作するタイミング

- 入力中・変換中だけ有効です。何も入力していないときは、そのキーはアプリケーションにそのまま渡ります（エディタの Ctrl+P などはそのまま使えます）。
- 組み込みと同じキーを指定すると、組み込みの動作を上書きします（上の例では Ctrl+I の🤖AI候補ビューと、変換中の Ctrl+P の前候補）。

## 動作一覧

| 動作 | 内容 |
|------|------|
| `hiragana` | 入力全体をひらがなにする |
| `katakana` | 入力全体を全角カタカナにする |
| `alphanumeric_full` | 打鍵したキーそのものを全角英数にする（`ｋａｎｊｉ`） |
| `alphanumeric_half` | 打鍵したキーそのものを半角英数にする（`kanji`） |
| `toggle_width` | 表示中の形の全角・半角を切り替える（ATOK の Ctrl+O）。カタカナ⇄半角カタカナ、全角英数⇄半角英数。ひらがなからは半角カタカナになる。全角・半角の区別がない文字（漢字など）はそのまま |
| `hiragana_mode` | 英数字モード・カタカナモードからひらがなモードに戻る（組み込みの 変換 キーと同じ。ATOK では Shift 単打） |
| `ai_candidates` | 🤖AI候補のビューを開く（組み込みの Ctrl+I） |
| `katakana_mode` | カタカナ入力モードに切り替える（組み込みの Ctrl+K） |

`hiragana` から `toggle_width` までは変換ウィンドウを開き、選んだ形を先頭に、ほかの形（ひらがな・カタカナ・半角カタカナ・全角英数・半角英数）を候補として並べます。Enter で確定、Space / ↓ で他の形、Escape で入力に戻ります。続けて別のキーを押せば、そのまま別の形に切り替わります。

英数の2つは、ローマ字テーブルを通す前の打鍵を使います。独自のローマ字テーブル（`romaji.tsv`）で `kd` → けん としていても、結果は `kd` です。入力の途中で文字を削除したりカーソルを動かして編集したりして打鍵と対応が取れなくなった場合は、読みをローマ字に直したもの（けん → `ken`）になります。英数の結果は学習しません。

## キーの書き方

`修飾キー+キー` の形で書きます。

- 修飾キー: `Ctrl`, `Alt`, `Shift`, `Super`
- キー: 英数字・記号1文字（大文字小文字は区別しない。Shift は `Shift+` で明示する）、`F1`〜`F12`, `Space`, `Tab`, `Enter`, `Escape`, `BackSpace`, `Delete`, `Home`, `End`, `Left`, `Right`, `Up`, `Down`, `Henkan`, `Muhenkan`

修飾キーなしの `"Shift"` だけを書くと、Shift キー（左右どちら）の**単打**を表します。Shift を押して、ほかのキーを挟まずに離したときだけ働きます。Shift+L で英数字モードに入ったときの Shift の離しは単打になりません。単打は入力中でなくても働き、離したことはアプリケーションにも伝わります。

解釈できない行はログに警告を出して無視します。

## オプション

`[options]` で ATOK 風の挙動を有効にできます。

```toml
[options]
uppercase_alphabet_lock = true
```

| オプション | 既定 | 内容 |
|------|------|------|
| `uppercase_alphabet_lock` | `false` | **大文字英字固定モード**。Shift+英字で英数字モードに入ったあと、Shift を離さずに2文字目の英字を打つと（`NHK`）大文字英字固定モードになります。このモードでは、Shift なしの英字を打った時点でひらがなモードに戻り、その英字がローマ字入力の1文字目になります（`NHK` → `ka` で「NHKか」）。変換キーや `hiragana_mode` を割り当てたキーでも抜けられます。2文字目の前に Shift を離した場合は通常の英数字モードです |
